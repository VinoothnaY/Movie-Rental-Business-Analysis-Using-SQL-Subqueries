# Movie Rental Business Analysis Dashboard

## 📌 Project Overview
This repository contains an end-to-end data analytics and business intelligence project focused on optimizing operations, revenue generation, and customer retention for a relational movie rental database. 

Utilizing structured subqueries, data pipeline extraction, and advanced Excel visualization strategies, this project bridges technical execution with executive-level business strategy. The final output delivers an interactive dashboard providing key stakeholders with a unified view of corporate operational health.

## 📊 Key Artifacts Included
1. **SQL Analytics Engine:** Comprehensively documented subqueries executing advanced table joins, aggregations, and performance filtering.
2. **Data Infrastructure (CSV):** Structured, clean datasets exported from the relational system serving as the database baseline.
3. **Excel Workbook:** PivotTable architecture, calculated fields, and a polished summary dashboard leveraging modern chart types (including a manual Pareto framework).
4. **Business Analysis Report:** A formal 2-page brief detailing catalog diagnostics, demand bottlenecks, and financial models.
5. **Executive Slide Deck:** High-impact presentation outline framing the top 5 strategic data findings.
